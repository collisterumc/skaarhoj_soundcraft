# skaarhoj_soundcraft
Skaarhoj Device Core for basic Soundcraft digital mixer control

## Development Container

This repository includes a VS Code Dev Container configuration in `.devcontainer/devcontainer.json`.

To use it:
1. Install [Docker](https://www.docker.com/) and the VS Code [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers).
2. Open this repository in VS Code.
3. Run `Dev Containers: Reopen in Container` from the Command Palette.
